PHASE 27 - OFFLINE VOICE SPEED OPTIMIZATION
-------------------------------------------
This update changes offline transcription from Whisper Small to Whisper Base
using faster-whisper INT8 on CPU. It reduces decoding beam size from 5 to 1,
uses a single best candidate, and configures six CPU threads. Push-to-talk
recording is shortened from 6.5 to 5.5 seconds; wake-listening chunks are
shortened from 4.5 to 3.5 seconds. These are speed/latency trade-offs and may
slightly reduce recognition accuracy, especially in noisy environments.

The Base model is a separate model download from Small. The first run after
this update needs internet to download it; later runs use the local cache.
The previous Small model cache is not deleted. To return to Small, change
WhisperModel("base"...) to WhisperModel("small"...) in server.py.

CPU performance varies by laptop power mode, background load, microphone
quality, and command length. Six CPU threads are a starting configuration;
this has not been benchmarked on the user's Windows laptop.


PHASE 28 — SECURE LOCAL STREAMING CHAT
======================================

This incremental update adds local Ollama token streaming to the normal chat
path. When the UI sends stream=true, the existing localhost server requests a
stream from Ollama at 127.0.0.1:11434 and forwards newline-delimited JSON
(token deltas) to the browser. The chat bubble updates as tokens arrive rather
than waiting for the complete answer. The completed assistant answer is saved
to the existing local SQLite conversation history.

No cloud AI provider, cloud speech API, or online TTS provider is configured.
The streaming endpoint uses the same loopback Host validation, same-origin
validation, JSON-only POST policy, request-size limit, and per-endpoint rate
limit as the normal chat endpoint. It emits no permissive CORS headers. Model
output is treated as text only; model-generated actions are not executed.
Robot simulation commands continue to use the deterministic explicit-command
allowlist. The server still binds only to 127.0.0.1.

Current Phase 28 scope and limitations:
- Chat text streams from local Ollama as tokens arrive.
- Voice transcription remains local faster-whisper Base INT8 (English and
  Malayalam supported by the multilingual model).
- The current voice UI still uses short MediaRecorder clips; this update does
  not yet provide true continuous/partial streaming ASR or sentence-by-sentence
  speech synthesis. Voice responses are spoken after the final answer arrives.
- Local TTS uses voices installed in Windows/browser. Voice quality and
  Malayalam availability depend on installed system voices.
- The page still references some third-party CDN assets (fonts, vision and
  hand-tracking libraries). They are not AI providers, but may make network
  requests and may not load offline. Full air-gapped operation requires
  auditing and bundling those assets locally in a later hardening pass.
